说明：
本项目为差速驱动器V1.1的开源代码，使用ESP32作为主控，通过WiFi创建热点，实现远程遥控控制。
连接wifi（默认名称：ESP32_V7_PI），密码（默认密码：<PASSWORD>），打开网页http://192.168.4.1 即可使用遥控器遥控。

使用说明：
左侧摇杆为小车底盘控制，右侧摇杆为云台控制，
中间滑块为水弹机炮控制（拉到最左侧或者最右侧等待几秒后等待机炮完全解锁可自动开火）。

代码结构：
main.py为主程序，包含wifi连接、遥控器控制、云台控制、水弹机炮控制等功能。
index.html为网页文件，通过http://192.168.4.1 访问。
index_o.html为保留备份文件，用于修改网页样式时参考。
boot.py为灯带，非必须。
flask_test.py为pc端测试文件，非必须（仅用于网页样式调试）。
microdot.py为micropython库文件
_softpwm.py为软件PWM文件。

注意事项：
由于esp32s3的PWM接口数量不足，因此在使用软件PWM时，部分只能使用_softpwm.py中的软件PWM。
由于使用软件PWM时，部分功能可能不准确，因此建议按需修改main.py中的PWM设置使用硬件PWM。
系统包含驱动4组H桥的8个PWM，驱动云台的2组pwm，驱动水弹机炮的1组pwm。
当前水弹pwm使用直接开关控制而不是PWM控制，控制倒车的H桥使用软件PWM。

特别注意：
严禁在安装电池时使用PD电源接口，否则可能导致致命损坏。
请确保您的水弹驱动器电机安装有启动电容，否则可能导致水弹无法正常启动，严重会烧毁mos管。
推荐使用标压（7.4V）水弹驱动器电机，否则建议使用外部电源供电或者调整PD的输出功率以满足需求。
本项目仅供学习交流使用，请勿用于商业用途。
