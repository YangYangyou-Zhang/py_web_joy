# py_web_joy

#### Description
基于flask、microdot等等框架，使得在树莓派香橙派等等python的Linux平台或者是micropython嵌入式平台提供一个web服务器，使得用户可以通过手机或者电脑打开网页使用虚拟摇杆操纵设备，例如机器人、无人车、无人机等等设备。在不久的将来，将会完成linux嵌入式端（完整python环境）和在esp平台（micropython环境）的全部开发工作。
